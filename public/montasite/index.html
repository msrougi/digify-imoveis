Integração Google
Dados reais, credenciais seguras.

    
O painel está preparado para receber Google Ads e Search Console por uma função segura no servidor. Para ativar, configure no Cloudflare:

    
  • Projeto no Google Cloud e OAuth 2.0
  • Developer Token e Customer ID do Google Ads
  • Acesso à propriedade sc-domain:imoveis.digify.live
  • Secrets no servidor — nunca no JavaScript público

    
Depois da conexão, o botão consulta volume médio mensal, concorrência, lances, impressões, cliques, CTR e posição.
